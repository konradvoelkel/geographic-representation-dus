# Geographic Representation DUS

Dieses Projekt dient zur Analyse und Darstellung geografischer Daten für Düsseldorf.

## Voraussetzungen

- Python 3.12 (oder kompatible Version)
- `pip` als Paketmanager

## Installation

1. Repository klonen oder als ZIP herunterladen und entpacken.

2. (Empfohlen) Virtuelle Umgebung anlegen und aktivieren:

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # macOS / Linux
   # oder unter Windows:
   # .venv\Scripts\activate
   ```

3. Benötigte Python-Pakete aus der `requirements.txt` installieren:

   ```bash
   pip install -r requirements.txt
   ```


## Ausführung

Nach erfolgreicher Installation der Pakete kann das Programm über die Datei `run.py` gestartet werden.
Der komplette Durchlauf des Programms dauert mehrere Stunden, bitte planen Sie entsprechend.
